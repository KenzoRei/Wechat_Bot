# Documentation archive

**Status:** Historical

Archived documents preserve project origin, superseded designs, retrospectives,
and collaboration evidence. They are not current operating instructions.

- `project-origin/` — kickoff, original requirements, early plans, scratchpads.
- `designs/` — detailed specifications superseded by current architecture and
  source code.
- `project-retrospective/` — learning and retrospective material.
- `collaboration/` — signed plans, reviews, and author-attributed transcripts.

Historical documents may contain stale paths or implementation claims. Follow
the current [documentation index](../README.md) for operational work.
